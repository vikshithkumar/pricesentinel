# Core Memory

## Key Files & Layout
- **Root Entrypoints**: [index.html](file:///D:/Into%20the%20Scrape-Verse/index.html), [src/main.tsx](file:///D:/Into%20the%20Scrape-Verse/src/main.tsx)
- **App Layout & Router**: [src/App.tsx](file:///D:/Into%20the%20Scrape-Verse/src/App.tsx) handles global shell structure, incorporating sidebar navigation, header, sub-header, and routing dashboard.
- **Main View**: [src/components/Dashboard.tsx](file:///D:/Into%20the%20Scrape-Verse/src/components/Dashboard.tsx) renders dashboard metrics, detections, impact graphs, health, and activity lists.
- **Mock Data**: [src/mockData.ts](file:///D:/Into%20the%20Scrape-Verse/src/mockData.ts) contains static metric telemetry, recent detections list, recommended actions, and health stats.
- **Styling Entrypoint**: [src/index.css](file:///D:/Into%20the%20Scrape-Verse/src/index.css) loads Tailwind directives and sets Inter as default font.
